# AI vs Non-AI Task Classification

| # | Question / Task | Needs AI? | Reason |
|---|---|---|---|
| 1 | Summarize a 20-page PDF document into key takeaways | Yes | Requires natural language understanding and semantic summarization. |
| 2 | Translate text from English to Vietnamese with contextual nuances | Yes | Requires complex natural language processing across multiple languages. |
| 3 | Generate code snippets based on free-form prompt descriptions | Yes | Involves complex pattern recognition and code generation reasoning. |
| 4 | Detect sentiment (positive/negative/neutral) in customer feedback | Yes | Requires contextual interpretation of human emotional tone. |
| 5 | Classify user queries into support categories automatically | Yes | Depends on intent classification through natural language understanding. |
| 6 | Extract entities (names, dates, locations) from unstructured text | Yes | Requires Named Entity Recognition (NER) models to identify context. |
| 7 | Rewrite a technical essay in a formal, professional tone | Yes | Involves stylistic rewrite and grammatical context restructuring. |
| 8 | Answer open-ended user questions about general knowledge | Yes | Requires retrieval and generation powered by a Large Language Model. |
| 9 | Analyze image content and describe objects present | Yes | Involves computer vision and multi-modal feature extraction. |
| 10 | Draft a personalized email response based on user history | Yes | Requires creative text generation adapted to personalized context. |
| 11 | Calculate the sum of two integers (e.g., $a + b$) | No | Deterministic arithmetic operation easily handled by standard code. |
| 12 | Check if a string contains a valid email address using regex | No | Can be completely solved using deterministic pattern matching. |
| 13 | Query a database for a user profile by exact User ID | No | Standard SQL query operation with fixed deterministic lookup. |
| 14 | Sort an array of numbers in ascending order | No | Standard algorithmic sorting (e.g., QuickSort) is fast and deterministic. |
| 15 | Validate if a password meets minimum length and character rules | No | Simple string length and character set logic checks. |
| 16 | Convert a timestamp into a formatted date string | No | Built-in datetime formatting functions handle this deterministically. |
| 17 | Check if a file exists in a given file system path | No | Standard operating system I/O call without complex reasoning. |
| 18 | Calculate the hash (SHA-256) of a file | No | Deterministic cryptographic hash function executed by CPU. |
| 19 | Parse a JSON string into a structured key-value object | No | Handled deterministically by standard JSON parsing libraries. |
| 20 | Check if a HTTP response status code indicates success (2xx) | No | Simple integer comparison logic (`200 <= code < 300`). |
