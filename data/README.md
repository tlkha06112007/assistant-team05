# Data Sources and Ownership

This directory contains the data files used by the assistant project.

## Data Files

| File | Description | Source | Owner | Update Frequency |
|---|---|---|---|---|
| `offices.csv` | Contains office information, including office name, room, and opening hours. | Project sample data (Lab 01) | Member 3 | Updated manually when office information changes. |

## Data Format

### `offices.csv`

The CSV file uses the following columns:

- `name`: Name of the office.
- `room`: Room number or location of the office.
- `hours`: Office opening hours.

## Data Maintenance

- Keep the CSV column names consistent with the expected data format.
- Verify data accuracy whenever the file is updated.
- Update this document whenever a data source, owner, or update frequency changes.
- Add new data files to the table above when they are introduced.

## Ownership

Member 3 is responsible for maintaining `offices.csv` and documenting its data source and update frequency.
